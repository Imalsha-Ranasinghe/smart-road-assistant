# Smart Road Assistant
### Real-time Traffic Light & Pothole Detection System

### Key Features
- Real-time traffic light detection and color classification (Red / Yellow / Green)
- Pothole detection with severity rating (Low / Medium / High) and distance estimation
- Robust performance under adverse weather conditions (rain, fog, night, wet road)
- Lightweight gate model that activates only the required detection pipeline
- Web-based demonstration interface (React frontend + Flask backend)

---

## System Pipeline

```
Input (Image / Video / Webcam)
        ↓
Common Preprocessing
(resize → CLAHE → denoise → weather correction)
        ↓
Gate Model — decides which pipelines to activate
        ↓
  ┌─────┴─────┐
Traffic     Pothole
Pipeline    Pipeline
  │               │
HSV color     Grayscale +
enhancement   edge sharpening
  │               │
Traffic       Pothole
Model         Model
  │               │
Color state   Severity +
(R/Y/G)       Distance
  └─────┬─────┘
        ↓
  Post Processing (NMS + confidence filter)
        ↓
  Warning Generation
        ↓
  Annotated Output + Audio Alert
```

## Models

| Model | Purpose | Architecture | Dataset |
|---|---|---|---|
| Gate model | Detects presence of TL or pothole | YOLOv8n | LISA + Bosch + Kaggle + Chitholian |
| Traffic light model | Classifies Red / Yellow / Green | YOLOv8s | LISA + Bosch |
| Pothole model | Detects and rates severity | YOLOv8s | Kaggle + Chitholian |

## Training

### Step 1 — Prepare datasets

Converts all raw annotations to YOLO format, splits into train/val/test, and builds the gate dataset.

```bash
python src/prepare_data.py
```

### Step 2 — Augment training data

Adds weather augmented copies (rain, fog, night, wet road) to improve robustness.

```bash
python src/augment.py
```

### Step 3 — Train models

```bash
# Train pothole model
python src/train.py --model pothole

# Train traffic light model
python src/train.py --model traffic

# Train gate model (train pothole + traffic first)
python src/train.py --model gate

# Train all models at once
python src/train.py --model all

# Train with augmented data
python src/train.py --model pothole --aug

# Train and evaluate
python src/train.py --model pothole --eval
```

> **Tip:** Use Google Colab with T4 GPU for faster training.  
> CPU training takes 5–10 hours. GPU training takes 20–40 minutes.

### Training order matters

```
1. pothole  (no dependency)
2. traffic  (no dependency)
3. gate     (requires pothole_yolo and traffic_yolo to exist)
```

## Phase-based Development

This project was built in two phases to allow development without all data available at once.

### Phase 1 — Pothole only
```
prepare_data.py   → pothole datasets only
augment.py        → pothole augmentation
train.py          → pothole model only
pipeline.py       → detects potholes only (auto)
```

### Phase 2 — Full system
```
prepare_data.py   → traffic + gate datasets added
augment.py        → traffic augmentation added
train.py          → traffic + gate models trained
pipeline.py       → full detection (auto, no code change)
```

The pipeline automatically detects which model files exist in `models/` and activates the appropriate detection pipelines. No code changes are needed between phases.
