SLIDE 2 — "CLEANING DASHCAM FRAMES"
Two CV/IP techniques on one slide
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Headline:  "We used the Laplacian operator and perceptual hashing to keep
            only the frames worth annotating."

LEFT HALF — BLUR DETECTION
  Technique:  Laplacian Operator (2nd-order derivative)
  Concept:    Sharp edges → high Laplacian response.
              Blurry edges → near-zero Laplacian response.
  Visual:     Show 2 rows side by side —
              Row 1: Sharp frame | Laplacian heatmap (bright, busy)  → KEPT
              Row 2: Blurry frame | Laplacian heatmap (dark, flat)   → REJECTED
  One number: Var > 60 = kept.  Var < 60 = rejected.

RIGHT HALF — DUPLICATE REMOVAL
  Technique:  Perceptual Hashing (DCT — same transform as JPEG)
  Concept:    Each frame is compressed to a 64-bit fingerprint.
              Two frames with ≤ 6 differing bits are considered identical.
  Visual:     Show 3 frames from the same stretch of road (nearly identical)
              → Only 1 kept, 2 rejected.
              Below each: show the tiny 8×8 DCT hash grid (black/white squares)

RESULT BAR at the bottom of the slide:
  108,000 raw frames  →  2,400 diverse, sharp frames

Headline:  "We unified 4 annotation formats and automatically generated
            severity labels using spatial analysis — no manual work."

TOP HALF — FORMAT UNIFICATION
  Show a simple conversion diagram:

  VOC XML  ──┐
  LISA CSV  ─┼──  coordinate normalisation  ──►  YOLO .txt
  Bosch YAML─┘         formula:                  class  xc  yc  w  h
  Our own   ─┘     xc = (xmin+xmax) / (2×W)     (all values 0–1)
                   w  = (xmax−xmin) / W

  One line to say: "YOLO needs normalised [0,1] coordinates.
                    All four formats used absolute pixel coordinates.
                    We converted every single annotation."

BOTTOM HALF — SEVERITY AUTO-LABELLING (the clever part)
  The insight: a larger bounding box = closer/bigger pothole = more dangerous.
  So we measure: box area ÷ image area

  Show 3 example images with bounding boxes of different sizes:

  [Small box]   ratio = 1.8%  →  LOW    (distant, small pothole)
  [Medium box]  ratio = 7%    →  MEDIUM (moderate)
  [Large box]   ratio = 15%   →  HIGH   (close, large pothole — HIGH DANGER)

  Then show the crop being extracted (ROI extraction: box + 10px padding → 128×128)

  One number:  "Zero manual severity annotations. All labels generated
                from geometry."

HOW TO GENERATE THE 5×5 GRID (run in a notebook cell):

  import sys; sys.path.insert(0, '../src')
  import cv2, matplotlib.pyplot as plt
  from pathlib import Path
  from augment import add_rain, add_fog, add_night, add_wet_road
  from augment import img_to_tensor, tensor_to_img

  imgs    = sorted((Path('..').resolve() /
                    'data/processed/detector_yolo/images/val').glob('*.jpg'))[:5]
  effects = [('Original', lambda t: t), ('Rain',     add_rain),
             ('Fog',      add_fog),     ('Night',    add_night),
             ('Wet Road', add_wet_road)]

  fig, axes = plt.subplots(5, 5, figsize=(16, 14))
  for col, p in enumerate(imgs):
      t = img_to_tensor(cv2.imread(str(p)))
      for row, (label, fn) in enumerate(effects):
          out = tensor_to_img(fn(t.clone()))
          axes[row][col].imshow(cv2.cvtColor(out, cv2.COLOR_BGR2RGB))
          axes[row][col].axis('off')
          if col == 0:
              axes[row][col].set_ylabel(label, fontsize=12,
                  fontweight='bold', rotation=0, labelpad=55, va='center')
  plt.suptitle('Weather Augmentation — Data Preprocessing',
               fontsize=14, fontweight='bold')
  plt.tight_layout()
  plt.savefig('augmentation_grid.png', dpi=150, bbox_inches='tight')
  plt.show()
